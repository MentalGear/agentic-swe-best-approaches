# You write the spec, the agent asks

jacobobryant writes spec files "exclusively by hand" and asks the agent to surface questions, which
they answer by editing the spec further. It stays more manageable than an agent-generated spec
([49852208](https://news.ycombinator.com/item?id=49852208)).

This directly answers the author's complaint that she was reviewing "decisions I didn't explicitly
make" — every decision in the spec is one you wrote.

Related stance: philbo wants agents to work "more like pair programming and less like code review.
I want to delegate typing, not thinking" ([49853739](https://news.ycombinator.com/item?id=49853739));
dsign deliberately leaves part of the work for themself to stay current on the project
([49852178](https://news.ycombinator.com/item?id=49852178)).
