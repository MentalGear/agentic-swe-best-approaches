# grill-me and grill-with-docs skills

- Repo: <https://github.com/mattpocock/skills> (grilling doc: `docs/productivity/grilling.md`)
- Install as quoted by mcapodici ([49854117](https://news.ycombinator.com/item?id=49854117)):
  `npx skills add mattpocock/skills --skill=grill-me`
- `/grill-with-docs` also recommended (MikeNotThePope, [49853818](https://news.ycombinator.com/item?id=49853818)).

diegof79 uses it more than plan mode and forked it to use Claude's question tool
([49851420](https://news.ycombinator.com/item?id=49851420)). valzam: "felt like a step change in the
output quality" ([49853409](https://news.ycombinator.com/item?id=49853409)). Dissent: SalariedSlave
finds the skill's own prose hard to read ([49854387](https://news.ycombinator.com/item?id=49854387)).

Read any third-party skill before installing; it runs with your agent's permissions. A minimal
local alternative: [templates/skills/interview/SKILL.md](../templates/skills/interview/SKILL.md).
