# obra/superpowers

<https://github.com/obra/superpowers>, suggested by nerdyadventurer ([49852503](https://news.ycombinator.com/item?id=49852503)).

Reception:

- stingraycharles: too much bloat; prefers a lightweight setup ([49852821](https://news.ycombinator.com/item?id=49852821)).
- Nursie: some skills "feel very cargo-culty"; a plain "review this PR, results in order of severity"
  does as well ([49852894](https://news.ycombinator.com/item?id=49852894)).
- plaguuuuuu: in their testing, more expensive and "markedly worse code organisation" than `/plan`,
  because the plan itself raises cognitive load for the model ([49853088](https://news.ycombinator.com/item?id=49853088)).

Anecdotes, not benchmarks. Recorded here so the graph shows the tradeoff.

## Update (refresh 2026-09-26): mixed, not only negative

- parasti's team uses it at work (plan → review → implement with high scrutiny) and rarely reads the
  resulting code; in Antigravity CLI it slowed the agent and produced worse plans ([49855463](https://news.ycombinator.com/item?id=49855463)).
- teliskr likes its brainstorming skill ([49856911](https://news.ycombinator.com/item?id=49856911)); mococa: too much time and tokens, and "a lot
  of useless testing" ([49857018](https://news.ycombinator.com/item?id=49857018)); teliskr agrees it would matter on a tighter budget
  ([49857199](https://news.ycombinator.com/item?id=49857199)).
